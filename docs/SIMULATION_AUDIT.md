# Supplied Unity Simulation — Audit Snapshot

**Audit source:** `Team apex.zip`, uploaded 27 November 2026. The repository was empty on branch `root` before this initial project import.

## What is present

The cleaned Unity project targets **Unity 6000.3.29f1**. The current implementation contains:

- Editable procedural Indian island-city simulation and saved scenes (`IndianIslandCity`, `NorthernPilot`).
- Serialized road-network metadata, metric geometry and lane records.
- Ground-truth map queries (`NearestLane`, `NearestRoad`, lane/intersection snapshots, signals and infrastructure lookup).
- Traffic-signal phase control with conflict-matrix validation and fail-closed all-red behavior for invalid configurations.
- Environment day/night and street-luminaire control.
- Edit-mode and play-mode Unity test assemblies.

The supplied `Documentation/IslandCounts.json` reports 68 roads, 228 lanes, 39 intersections, 397 movements, 9 signalised junctions, 105 signal heads, 357 streetlights, 2 bridges, 400 buildings and 8 districts. These are values recorded by the supplied project artifacts; they are not independently re-generated by this web-console task.

`Documentation/OfflineValidation.json` lists 13 offline validation checks as `PASS`, including road graph connectivity, lane boundaries, movement conflicts, signal references, mesh validity, scene/build entry references and illumination components.

## What was not found in the inspected Unity scripts

The inspected source contains **no implemented camera capture pipeline, YOLO detector, object tracker, movement estimator, trajectory predictor, collision predictor/risk assessor, UDP sender/receiver or cooperative risk-fusion module**. No live sensor stream or two-device communication test was available in the uploaded project.

The browser Scenario Lab in `web-console/` therefore operates on temporary manual test data only. It does not connect to or alter the Unity scene.

## Validation boundaries

- The statuses above are grounded in the uploaded project's files (`Documentation/OfflineValidation.json`, `IslandCounts.json`, `PilotValidation.json`, `DevelopmentProgress.md`, scripts and tests).
- This audit did not run the Unity Editor, compile the project in Unity, or execute the Unity Test Runner. Those checks remain **NOT RUN** in this environment.
- The file `DevelopmentProgress.md` in the uploaded project records the original 26 November checkpoint; it should be updated by the team as new Unity Editor validation is performed.
